# rag_too
A production-ready Retrieval-Augmented Generation (RAG) API built with FastAPI, enabling semantic search and AI-powered question answering over custom documents using vector embeddings and Large Language Models (LLMs).
Features
🚀 FastAPI REST API
📄 Document ingestion (PDF, DOCX, TXT, Markdown)
✂️ Intelligent text chunking
🔎 Semantic search using vector embeddings
🧠 Retrieval-Augmented Generation (RAG)
💬 Context-aware question answering
📦 Pluggable vector databases (FAISS, ChromaDB, Pinecone, Qdrant)
🤖 Compatible with OpenAI, Ollama, Hugging Face, Azure OpenAI, and other LLM providers
⚡ Async endpoints for high performance
📚 Automatic Swagger/OpenAPI documentation
🐳 Docker support
🔒 Environment-based configuration
Tech Stack
FastAPI
Python 3.11+
LangChain / LlamaIndex (optional)
FAISS / ChromaDB
Sentence Transformers / OpenAI Embeddings
OpenAI / Ollama / Hugging Face LLMs
Pydantic
Uvicorn
